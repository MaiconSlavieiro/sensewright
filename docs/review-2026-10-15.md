# Runtime review — 2026-10-15

This offline review supersedes the old test totals and missing-implementation
claims in the October 2–9 snapshots. It is not an M8 in-game acceptance report.

## Corrections

| Area | Defect and correction |
|---|---|
| Save As | A new slot lost the active session's state. Copy the working database, including unsaved memories/metadata; remap neighborhood state; preserve the source checkpoint; reject an explicitly mismatched source. Tests now cover an uninterrupted session rather than starting a second session first. |
| Tick coalescing | Later ticks discarded drained action outcomes. Preserve all outcomes while merging census fields and retaining the latest clock. |
| Queue saturation | Saves/chat could be rejected while expendable events occupied the queue. Evict the oldest event without reordering retained requests. Saturation containing only non-droppable requests remains bounded and logs rejection. |
| SSE recovery | Clean EOF caused immediate reconnects; read timeouts never activated polling fallback. Count both as failures, wait between attempts and reset failures only on valid frames/keepalives. |
| HTTP | Explicitly close ordinary responses after reading, including when decoding fails. |
| Build | Script packaging now depends on package generation even under parallel make. Always rebuild to include changes to builders, icons and generated tuning IDs. |
| Localization | Three System labels existed only in the Mod locale bundle, while the builder prefers the sidecar bundle. Add the missing sidecar strings, validate tuning references against both bundles, and fail the build on unresolved STBL references. |

- **In-game acceptance remains:** Mirror/Mailbox/Diary clicks, Dev Mode and
  icons, full God Director arc, lot transition, Save As, exit-without-save
  rollback, shutdown/restart and invisible autoboot. Offline regressions do
  not validate the actual TS4 hooks.
- **Product work remains:** FC1 three-option onboarding (currently a
  notification), orphan confidant cleanup validated by a game probe, and FC5
  compatibility beyond installed-mod detection.
- **Deferred:** physical autobiography book, tombstone epitaph and MCP layer.
  Sleep balloons remain best effort.
- **Concurrency:** per-operation store/state locks do not establish atomicity
  of every lifecycle sequence against background callbacks. Save/transition
  stress testing remains necessary; this review does not certify all races
  eliminated.

## Verification and acceptance

Full suite: **822 passed**, one Starlette/httpx deprecation warning. The focused
artifact/transport/persistence checks also passed (33 tests). Python 3.7.9
compilation, bytecode magic verification and both artifact builders passed.
GNU Make was unavailable; dependency ordering was inspected and builders were
executed directly in package/script order.
Windows sandbox restrictions blocked temporary SQLite backup rotation and
hid Python 3.7; verification was rerun outside the sandbox. The Starlette/httpx
dependency deprecation warning remains. Artifacts are in `mod/dist/`; they
are not committed or automatically installed.
